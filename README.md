## 📝 Note

This is the new home & successor to [Espresso](https://github.com/mitchtreece/espresso) by [@mitchtreece](https://github.com/mitchtreece). This library aims to be a slimmed down, modern, & common dependency between other frameworks - though some might find the types, helpers, & sugar here useful on their own. This won't be an immediate replacement for the existing library. Things will only be cleaned up & pulled in as needed.

## 💾 Installation

The easiest way to get started is by installing via Xcode. Just add the library as a Swift package & choose the modules you want. If you're adding this as a dependency of your own Swift package, add a package entry to your dependencies.

```swift
.package(
    name: "Espresso",
    url: "https://github.com/superepicstudios/espresso",
    .upToNextMajor(from: "0.0.1")
)
```
